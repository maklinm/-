# -
Данная программа предназначена для осуществления управления виртуальным тренажером Радиолокационной станции 35Н6.
Установка программы:
1. Чтобы установить программу Вам необходимо установить архив программы
2. Разархивировать zip-файл, и поместить в папку тренажер по пути C:/
3. Зайти по пути тренажер/Тренажерный комплекс/GlaMenu/GlaMenu/bin/Release и разархивировать zip-файл в тот же каталог где он был размещен.
4. Зайти по пути тренажер/Exe/Unity/VTKcompleks_Data и разархивировать zip-файл в тот же каталог где он размещен.
5. Перейти в каталог тренажер/Тренажерный комплекс/GlaMenu/GlaMenu/bin/Release и создать файл-ярлык для удобного запуска приложения.
